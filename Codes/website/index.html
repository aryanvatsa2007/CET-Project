Reduce any derivative

Pick the property that changes, the property you vary, and the one you hold constant. All 336 combinations of eight state variables reduce exactly to temperature, pressure, volume, entropy, heat capacity, expansivity and compressibility.

U internal energy, H enthalpy, A Helmholtz energy, G Gibbs energy, S entropy. CP is the isobaric heat capacity, α the expansivity and κT the isothermal compressibility.

Run it yourself

The engine is a small Python package that needs only NumPy and SciPy. One script regenerates every data file, figure and number in the paper.

  1. Install the two dependencies.

    pip install numpy scipy matplotlib pytest

  2. Reduce a derivative from the command line.

    cd Codes
python -m thermocalculus derive "(dT/dP)_H"

  3. Run a scenario file and read its output.

    python -m thermocalculus run ../Data/inputs/01_state_co2_pr.txt -o out

  4. Regenerate everything and run the tests.

    python run_all.py
python -m pytest -q

What the engine cannot do

It treats one pure fluid in one phase per state. Mixtures, reactions and solids are outside its scope, and only first derivatives are reduced. Only carbon dioxide and nitrogen are in the database. Cubic equations are inaccurate near the critical point and for liquid density. Heat capacities derived from a coarse table of volumes are not reliable. For reference-quality properties use a dedicated library such as CoolProp or NIST REFPROP.
